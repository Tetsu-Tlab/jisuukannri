# 授業進捗管理システム

小中学校の先生向けの授業進捗管理Webアプリケーションです。

## 機能

### 📚 年間計画管理
- 年間計画の作成・編集
- PDFファイルのアップロード対応
- Googleスプレッドシートからのインポート
- 単元ごとの実施済みチェック
- 進捗率の可視化

### 📅 時間割入力
- 授業実施内容の記録
- **次の未実施単元の自動提案機能**
- 日付・時限・教科の管理
- メモ・備考の記録

### 📊 進捗確認
- 教科別進捗状況のグラフ表示
- 全体進捗率の円グラフ
- 月別進捗（予定 vs 実績）の比較
- 教科別詳細テーブル

## 技術スタック

- **フロントエンド**: Next.js 16 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **グラフ**: Recharts
- **データベース**: Supabase (予定)
- **認証**: Supabase Auth (予定)

## セットアップ

### 前提条件

- Node.js 18以上
- npm または yarn

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/Tetsu-Tlab/jisuukannri.git
cd jisuukannri

# 依存パッケージをインストール
npm install

# 開発サーバーを起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

## 対応デバイス

- ✅ デスクトップPC（Windows/Mac/Linux）
- ✅ タブレット（iPad等）
- ✅ **Chromebook**
- ✅ スマートフォン

レスポンシブデザインにより、すべてのデバイスで快適に使用できます。

## 使い方

1. **年間計画管理**: 教科書のPDFをアップロードするか、Googleスプレッドシートから年間計画をインポート
2. **時間割入力**: 実施した授業内容を記録（未実施の次の単元が自動提案されます）
3. **進捗確認**: クラスごと・教科ごとの進捗状況をグラフで確認
